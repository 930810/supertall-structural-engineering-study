# 초고층구조공학특론 스터디

초고층구조공학특론 중간시험 대비를 위한 전체 범위 모의시험, 강의별 객관식 퀴즈와 근사해석 계산 연습 자료입니다.

## 웹에서 바로 응시

[시험·연습 목록 열기](https://930810.github.io/supertall-structural-engineering-study/)

목록 맨 위의 **최종보스 시험 시작**으로 전체 범위를 연습하거나, 원하는 강의의 **시험 시작** 또는 계산 연습의 **연습 시작**을 선택하세요.

## 최종 모의시험: 최종보스 ★

[최종보스 열기](최종보스.html)

L01–L04 전체 범위를 섞은 **20개 랜덤 케이스**를 제공합니다. 각 케이스는 **46문항·100점**, 제한시간은 **60분**입니다.

| 구성 | 문항 수 | 배점 |
|---|---:|---:|
| L01 객관식 | 8 | 16점 |
| L02 객관식 | 14 | 28점 |
| L03 객관식 | 17 | 34점 |
| L04 객관식 | 6 | 12점 |
| L03 숫자 풀이 | 1 | 10점 |
| 합계 | 46 | 100점 |

객관식은 보기 4개와 정답 1개이며, 총 45문항을 문항당 2점으로 채점합니다. L03 풀이식은 숫자 답안을 입력하는 1문항입니다. **시험 시작**을 누르면 60분 타이머가 작동하며, 시간 종료 시 자동 제출됩니다. 제출 후 채점 결과와 정답·풀이를 확인할 수 있습니다.

사용자가 전달한 중간시험 공지의 시간표는 **10월 17일 10:30~11:30, 총 60분**입니다. 이 모의시험은 강의자료에 근거한 연습문제로 실제 시험문제를 보장하지 않습니다.

## 객관식 퀴즈

각 파일은 V01부터 V20까지 20개 케이스를 제공합니다. 제한시간은 강의에 따라 5분·8분·10분이며, 시간 종료 시 자동 제출되고 채점 결과·정답·해설이 표시됩니다.

| 강의 | 파일 | 케이스당 문항 수 | 제한시간 |
|---|---|---:|---|
| L01 강의소개 | [문제-01_강의소개.html](문제-01_강의소개.html) | 8 | 5분 |
| L02 초고층의 역사 | [문제-02_초고층의 역사.html](문제-02_초고층의%20역사.html) | 14 | 8분 |
| L03 초고층 구조시스템 | [문제-03_초고층 구조시스템.html](문제-03_초고층%20구조시스템.html) | 17 | 10분 |
| L04 동영상강의 | [문제-04_동영상강의.html](문제-04_동영상강의.html) | 6 | 5분 |

L03 객관식 파일에는 풀이식 시험 문항을 포함하지 않습니다. 각 문제는 강의자료를 바탕으로 만든 연습문제입니다.

## 사용 방법

1. [시험·연습 목록](https://930810.github.io/supertall-structural-engineering-study/)을 엽니다.
2. **최종보스 ★**, 강의별 객관식 또는 계산 연습을 선택합니다.
3. 최종보스와 강의별 객관식은 케이스를 선택한 뒤 **시험 시작**을 누릅니다.
4. 최종보스에서는 객관식 보기를 고르고 L03 숫자 풀이의 답안을 입력합니다. 60분 안에 제출하거나 시간 종료 시 자동 제출된 채점 결과·정답·풀이를 확인합니다.

모든 HTML은 CSS와 JavaScript를 파일 안에 포함합니다. **Code → Download ZIP**으로 내려받아 압축을 풀면 인터넷 연결 없이도 사용할 수 있습니다. GitHub의 파일 화면에서는 HTML 소스가 표시되므로, 웹 응시는 위 시험·연습 목록 주소를 이용하세요.
