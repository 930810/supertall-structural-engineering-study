## 사용 방법

1. 이 저장소에서 **Code → Download ZIP**으로 자료를 내려받습니다.
2. 압축을 풀고 원하는 HTML 파일을 Chrome 또는 Edge에서 엽니다.
3. 객관식은 버전을 선택한 뒤 **시험 시작**을 누릅니다.

모든 HTML은 CSS와 JavaScript를 파일 안에 포함하므로 추가 설치나 인터넷 연결 없이 사용할 수 있습니다. GitHub의 파일 화면에서는 HTML 소스가 표시됩니다.
