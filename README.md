# 초고층구조공학특론 스터디

초고층구조공학특론 중간시험 대비를 위한 객관식 퀴즈와 근사해석 계산 연습 자료입니다.

## 웹에서 바로 응시

[시험·연습 목록 열기](https://930810.github.io/supertall-structural-engineering-study/)

목록에서 원하는 강의의 **시험 시작** 또는 계산 연습의 **연습 시작**을 누르면 바로 응시할 수 있습니다.

## 객관식 퀴즈

각 파일은 V01부터 V20까지 20개 케이스를 제공합니다. 제한시간은 강의에 따라 5분·8분·10분이며, 시간 종료 시 자동 제출되고 채점 결과·정답·해설이 표시됩니다.

| 강의 | 파일 | 케이스당 문항 수 | 제한시간 |
|---|---|---:|---|
| L01 강의소개 | [문제-01_강의소개.html](문제-01_강의소개.html) | 8 | 5분 |
| L02 초고층의 역사 | [문제-02_초고층의 역사.html](문제-02_초고층의%20역사.html) | 14 | 8분 |
| L03 초고층 구조시스템 | [문제-03_초고층 구조시스템.html](문제-03_초고층%20구조시스템.html) | 17 | 10분 |
| L04 동영상강의 | [문제-04_동영상강의.html](문제-04_동영상강의.html) | 6 | 5분 |

L03 객관식 파일에는 풀이식 시험 문항을 포함하지 않습니다. 각 문제는 강의자료를 바탕으로 만든 연습문제입니다.

## 사용 방법

1. [시험·연습 목록](https://930810.github.io/supertall-structural-engineering-study/)을 엽니다.
2. 원하는 강의나 계산 연습을 선택합니다.
3. 객관식은 버전을 선택한 뒤 **시험 시작**을 누릅니다.

모든 HTML은 CSS와 JavaScript를 파일 안에 포함합니다. **Code → Download ZIP**으로 내려받아 압축을 풀면 인터넷 연결 없이도 사용할 수 있습니다. GitHub의 파일 화면에서는 HTML 소스가 표시되므로, 웹 응시는 위 시험·연습 목록 주소를 이용하세요.
